# A python GIF overlay for linux.
Currently checked only on CachyOs(wayland, KDE plasm).

I'll try my best to fix errors.

To use:
```
python pgif.py
```

Flags:
- -conf<br>Opens configuration menu
- example.gif<br>Opens that exact file
- conf=example<br>Uses that profile(i will change it soon to prof=example)

I will need some help for the transparency support, though.
